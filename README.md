### Description
This is a moon I'm currently working on for V81!

Originally called this moon "Opalite-28", but I renamed it. Becoming a sister moon/orbiting 48-Velit by WaterGun, or is it 84-Velit? idk.  

<details>
    <summary>Click to expand SPOILERS</summary>

This moon contains:

> 1 Fire Exit and 1 Main Enterance, with a Smaller exterior size and interior compared to many moons.

> 1 custom Enterance and Facility. (Primary Dam Control) where an apparatus can be taken to power the controls to the dam. The facility is always the same other than the Lockers being slightly randomized. It does have only a few scrap spawners.

> One (unfortunately unserious) silly custom scrap item which spawns in the basin of the reservoir when drained.

The idea of the dam control room requiring an entire apparatus just for the activation of the floodgate is excessive in hindsight given the scope of the dam.

### Folder Structure
> There is a specific way that I've decided to include the project files inside of the repository for keeping the project version controlled and safe on the web, and I guess public.

```
OpaliteMoonProject/
├──  LC Mod Testing/    - unity project root
│   ├──  Assets/                       
│   │   ├──  LethalCompany/          
│   │   │   ├──  Mods/                 
│   │   │   │   ├──  plugins/          
│   │   │   │   │   └──  OpaliteMod/  -- files here for the project included here
│   ├──  ProjectSettings/
│   └──  Packages/
```

> So I figured I could include my entire lethal company asset rip project within my local repository, then gitignore all the files outside of the OpaliteMod folder.

> I might keep this same or similar workflow going forwards as I think it should work fine for anyone wanting to open the project for themselves as long as they have an empty asset rip project already.

> I will not be testing if this works out-of-the-box anytime soon so if you are the first, expect it to be cumbersome and probably require communication with me if you REALLLY want the project to work, I assume no one cares though.
